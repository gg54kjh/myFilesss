Служба, которую вы заметили, называется wsappx. Вы абсолютно правы — она напрямую связана с Центром обновлений Windows и магазином приложений Microsoft Store. 
Несмотря на то, что официальная поддержка Windows 10 завершена и крупные системные обновления больше не приходят, встроенные приложения (такие как "Почта", "Калькулятор", "Фотографии" и др.) всё ещё пытаются фоново обновляться через Microsoft Store. В момент включения компьютера wsappx вместе с Центром обновлений начинает проверять, скачивать и устанавливать эти апдейты, что намертво загружает процессор и жесткий диск в первые минуты работы. 
Убрать эту нагрузку и усмирить службу можно несколькими простыми шагами: 
Шаг 1. Отключите автоматическое обновление приложений
Это главный виновник активности wsappx. 
  1. Откройте Microsoft Store (иконка белой сумки в меню «Пуск»).
  2. Кликните по иконке своего профиля (или трем точкам) в верхнем правом углу и выберите «Настройки».
  3. Переведите переключатель «Обновлять приложения автоматически» в положение Откл. 
Шаг 2. Очистите кэш обновлений (если процесс "завис")
Иногда служба грузит систему бесконечно из-за того, что скачался поврежденный файл обновления, и система пытается установить его по кругу. Чтобы сбросить этот цикл: 
  1. Нажмите комбинацию клавиш Win + R, введите services.msc и нажмите Enter.
  2. Найдите в списке службу «Центр обновления Windows» (Windows Update), нажмите по ней правой кнопкой мыши и выберите «Остановить».
  3. Откройте «Проводник» и перейдите по пути: C:\Windows\SoftwareDistribution.
  4. Выделите и удалите все файлы и папки внутри папки SoftwareDistribution (это очистит зависший кэш).
  5. Вернитесь в службы и снова включите «Центр обновления Windows» (или просто перезагрузите компьютер). 
Шаг 3. Ограничьте фоновую работу приложений
Даже если приложения не обновляются, они могут бодрствовать в фоне и дергать службу wsappx. 
  1. Откройте Параметры (сочетание клавиш Win + I) -> Конфиденциальность.
  2. Слева прокрутите вниз до пункта «Фоновые приложения».
  3. Отключите ползунок «Разрешить приложениям работать в фоновом режиме» (или выключите только те, которыми не пользуетесь). 
После выполнения этих трех шагов и следующей перезагрузки компьютер должен запускаться значительно быстрее, а процесс wsappx перестанет беспокоить систему на старте.

Вы абсолютно правы, что не стали делать Шаг 2 — при кратковременной нагрузке в несколько минут кэш действительно ни при чем. То, что Microsoft Store удален через PowerShell, а фоновые приложения выключены, значительно сужает круг причин. 
Дело в том, что служба wsappx состоит из двух подслужб: AppXSVC (служба развертывания AppX) и ClipSVC (служба лицензирования клиентов). Даже если самого магазина нет, в системе остаются встроенные системные компоненты формата AppX (например, элементы интерфейса, меню «Пуск» или «Поиск»), которые Центр обновлений Windows все равно проверяет при старте на целостность и лицензии. 
Поскольку обычные методы вам не подходят, усмирить этот пятиминутный запуск можно радикальным, но безопасным путем — через Редактор реестра. Это полностью запретит службе wsappx запускаться автоматически. 
Как полностью отключить запуск wsappx через Реестр
  1. Нажмите сочетание клавиш Win + R, введите regedit и нажмите Enter (откроется Редактор реестра).
  2. В адресную строку сверху вставьте следующий путь и нажмите Enter:
    HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\AppXSvc
  3. В правой части окна найдите параметр с именем Start и дважды кликните по нему.
  4. Измените его значение с 3 (или 2) на 4 (значение 4 означает «Отключено»). Нажмите ОК.
  5. (Дополнительно) Перейдите в соседнюю папку по пути:
    HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\ClipSVC
    И точно так же измените значение параметра Start на 4.
  6. Перезагрузите компьютер. 
Что это изменит: При старте Windows Центр обновлений больше не сможет разбудить службу wsappx. Процесс полностью перестанет нагружать систему. Поскольку магазин у вас уже удален, это никак не повлияет на повседневную работу компьютера. 
Если после перезагрузки Центр обновлений Windows все еще продолжает грузить систему сам по себе (уже без этой службы), дайте знать. Мы можем настроить его так, чтобы он проверял обновления только вручную, раз система больше не поддерживается. Будем отключать сам Центр обновлений?

Ответ в режиме ИИ, исходный запрос: "А если отключить Центр обновлений, Windows Defender сможет получать обновления своих баз?"

Нет, если полностью отключить службу Центра обновлений Windows (wuauserv), встроенный Защитник Windows (Windows Defender) перестанет получать обновления баз автоматически в фоновом режиме. 
Если вы хотите убрать нагрузку от поиска обновлений ОС, но сохранить актуальную защиту, у вас есть три пути: 
Вариант 1. Запретить обновления ОС, но оставить базы (Рекомендуемый)
Вместо полного отключения службы, можно через локальные групповые политики (если у вас Windows 10 Pro) или реестр перевести Центр обновлений в режим «Только уведомлять о скачивании».
При таком сценарии Windows сама по себе ничего искать и ставить не будет (и грузить ПК перестанет), но для Защитника останется лазейка, и он продолжит втихую обновлять свои базы. 
Вариант 2. Обновлять Защитник вручную по кнопке
Если вы всё же решите отключить службу обновлений, базы Защитника можно обновлять вручную: 
  1. Откройте Безопасность Windows (иконка щита у часов) -> Защита от вирусов и угроз.
  2. Прокрутите вниз до пункта «Обновления защиты от вирусов и угроз» и нажмите «Обновления защиты».
  3. Нажмите кнопку «Проверить наличие обновлений». Антивирус умеет скачивать базы напрямую с серверов Microsoft, минуя сломавшуюся или отключенную службу Windows Update. 
Вариант 3. Настроить автообновление через PowerShell / Планировщик задач
Можно полностью отключить Центр обновлений, но заставить Windows Defender обновляться, например, раз в сутки через встроенную команду.
Для этого в PowerShell от имени администратора достаточно выполнить: 
powershell
Update-MpSignature -UpdateSource MicrosoftUpdateServer
Эту команду можно один раз зашить в стандартный «Планировщик задач» Windows, чтобы она выполнялась раз в день в фоновом режиме, вообще не трогая общую систему обновлений ПК.

Поскольку у вас Windows 10 Home, в ней отсутствует стандартный Редактор групповых политик. Однако решить проблему и сохранить обновления Защитника можно через Редактор реестра, переведя Центр обновлений в ручной режим, либо настроив Защитник в обход системы. 
Вот два лучших способа для вашей редакции: 
Способ 1. Перевод Центра обновлений в режим «Только уведомления» (Через Реестр)
Это самый надежный способ. Windows перестанет автоматически искать и скачивать обновления ОС на старте компьютера (что уберет нагрузку), но Защитник Windows сохранит доступ к серверам и продолжит обновлять базы в фоне. 
  1. Нажмите Win + R, введите regedit и нажмите Enter.
  2. В адресную строку сверху вставьте путь:
    HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows
  3. Посмотрите, есть ли в левой колонке внутри папки Windows папка с именем WindowsUpdate. Если ее нет, нажмите правой кнопкой мыши по папке Windows -> Создать -> Раздел и назовите его WindowsUpdate.
  4. Нажмите правой кнопкой мыши уже по созданной папке WindowsUpdate -> Создать -> Раздел и назовите его AU.
  5. Зайдите в папку AU. В правой (пустой) части окна нажмите правой кнопкой мыши -> Создать -> Параметр DWORD (32 бита). Назовите его AUOptions.
  6. Дважды кликните по AUOptions и установите значение 2 (это означает «Уведомлять перед загрузкой»). Нажмите ОК.
  7. Перезагрузите компьютер. 
Результат: Фоновая автоматическая проверка обновлений Windows прекратится. При этом базы Защитника будут скачиваться сами, так как для них сделано исключение на системном уровне. 
Способ 2. Полное отключение обновлений + Автоматизация Защитника
Если вы хотите полностью и гарантированно заблокировать Центр обновлений, но не хотите обновлять антивирус вручную кнопкой в интерфейсе, можно автоматизировать команду PowerShell: 
  1. Полностью отключите службу «Центр обновления Windows» через services.msc (смените тип запуска на «Отключена»).
  2. Нажмите «Пуск», начните вводить Планировщик задач и откройте его.
  3. В колонке справа нажмите «Создать простую задачу...».
  4. Назовите её, например, «Обновление Защитника». Нажмите Далее.
  5. В триггере выберите «Ежедневно» и укажите удобное время (например, через 15–20 минут после того, как обычно включаете ПК, чтобы избежать нагрузки на старте).
  6. В действии выберите «Запустить программу».
  7. В поле «Программа или сценарий» введите: powershell.exe
  8. В поле «Добавить аргументы (необязательно)» вставьте команду:
    -Command "Update-MpSignature -UpdateSource MicrosoftUpdateServer"
  9. Нажмите Далее и Готово. 
Теперь Центр обновлений мертв и систему не трогает, а Защитник раз в день сам забирает свежие базы напрямую с серверов Microsoft.
