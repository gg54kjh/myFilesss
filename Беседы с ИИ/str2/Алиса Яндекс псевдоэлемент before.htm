В коде веб-страницы есть тег <strong> и в нём строка текста. Как с помощью псевдоэлемента ::before сделать, чтобы этой строке предшествовала моя строка? Т. е. сначала мой текст, буквально несколько символов, затем пробел, а потом уже строка которая должна быть.

Чтобы добавить свой текст перед содержимым тега <strong> с помощью псевдоэлемента ::before, нужно использовать свойство content.

Простой вариант

HTML:

<strong>Исходный текст</strong>

CSS:

strong::before {
  content: "Ваш текст "; /* обязательно пробел в конце строки */
}

Результат в браузере:

Ваш текст Исходный текст.

Важные нюансы

  1. Свойство content обязательно. Без него псевдоэлемент не отобразится.
  2. Пробел нужно включить прямо в строку content (как в примере выше) — так надёжнее, чем пытаться добавлять его через margin или другие свойства.
  3. По умолчанию ::before — строчный элемент, поэтому текст встанет в одну строку с содержимым <strong>.

Если нужно стилизовать добавленный текст отдельно

Можно задать для ::before свои стили — например, цвет, жирность и т. п.:

strong::before {
  content: "→ ";
  color: #666;
  font-weight: normal;
  margin-right: 4px; /* дополнительный отступ, если нужен */
}

Если у <strong> уже есть свой ::before

Если на элементе уже используется ::before (например, в каком‑то фреймворке), второй псевдоэлемент добавить нельзя: у элемента может быть только один ::before. В таком случае есть варианты:

  • Обернуть <strong> в другой тег (например, <span>) и ставить ::before на обёртку.

  • Добавить нужный текст прямо в HTML.

  • Использовать атрибут (например, data-prefix) и брать значение через content: attr(data-prefix):

    HTML:
    <strong data-prefix="→ ">Исходный текст</strong>

    CSS:
  strong::before {
  content: attr(data-prefix);
}


А с before обязательно нужно два двоеточия, или можно и одно?

Обязательно использовать два двоеточия — ::before.

В чём разница

  • ::before (два двоеточия) — это псевдоэлемент по современной спецификации CSS (CSS3 и новее). Так нужно писать сейчас.
  • :before (одно двоеточие) — старый синтаксис из CSS2. Браузеры его до сих пор поддерживают ради обратной совместимости, но это считается устаревшим вариантом.
